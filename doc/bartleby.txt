==============================================================================
Bartleby                                                     *bartleby-bartleby*

A structured writing environment for Vim. It provides a binder, a corkboard,
an outliner, and a compile pipeline for long-form prose and screenplays.

------------------------------------------------------------------------------
Bartleby                                                   *bartleby-bartleby-1*

A project, called a scrive, is a tree of folders and documents. You build and
arrange the tree in a sidebar, shuffle scenes on a corkboard, review them in
an outline, and compile the tree into a submission manuscript, a typeset book,
or a screenplay.

Every document is a plain `.md` file, or a `.fountain` file for screenplays. A
small JSON file next to each document holds its metadata: label, status,
synopsis, keywords, and word-count target. The tree itself is one
`project.json` per scrive. You can edit all of these files with any editor.

------------------------------------------------------------------------------
Requirements                                             *bartleby-requirements*

- Vim 9.2 or newer, with `+popupwin`. |bartleby-footnote1|
- Logger https://github.com/Galvarcus/Logger - a Vim9script logging utility
  that Bartleby uses. Install it the same way as Bartleby.
- Compile needs Pandoc https://pandoc.org 3.x and a LaTeX distribution with
  `pdflatex`, `xelatex`, and the sffms https://ctan.org/pkg/sffms class.
  Screenplays need screenplain https://github.com/vilcans/screenplain instead.
- Dictionary and thesaurus need `curl` and your own free
  Merriam-Webster API keys https://dictionaryapi.com, one for the Collegiate
  Dictionary and one for the Collegiate Thesaurus.
- Spotlight's Nouns, Verbs, Adjectives, and Passive modes need Python 3 with
  spaCy https://spacy.io and its English model. See Spotlight modes
  #spotlight-modes.

Writing needs only Vim. Compile, the lookups, and the tagger modes are the
only features with other requirements.

------------------------------------------------------------------------------
Installation                                             *bartleby-installation*

Install Logger and Bartleby the same way.

With vim-plug https://github.com/junegunn/vim-plug:

>vim
    Plug 'Galvarcus/Logger'
    Plug 'Galvarcus/bartleby'
<
With Vim's native packages:

>sh
    git clone https://github.com/Galvarcus/Logger ~/.vim/pack/plugins/start/Logger
    git clone https://github.com/Galvarcus/bartleby ~/.vim/pack/plugins/start/bartleby
<
With Lazy.nvim https://github.com/folke/lazy.nvim or a similar manager:

>lua
    { 'Galvarcus/Logger' },
    { 'Galvarcus/bartleby' }
<
Restart Vim, then create a scrive to confirm that Bartleby loaded:

>vim
    :BartlebyNewScrive TestProject
<

------------------------------------------------------------------------------
Quick start                                               *bartleby-quick-start*

>vim
    :BartlebyNewScrive My Novel
<
Bartleby asks for the scrive type: novel, novel with parts, short story, or
screenplay. It creates the scrive under `g:bartleby_binder_root` and opens the
Binder with a starter tree: Front Matter, Manuscript with a first chapter and
scene, Back Matter, Characters, and Research.

In the Binder:

- `<CR>` on a document opens it.
- `a` adds a document. `A` adds a folder.
- `go` opens the Outliner for the folder under the cursor. `gc` opens its
  Corkboard.

Elsewhere:

- `<leader>bi` toggles the Inspector for the current document.
- `:BartlebyCompile` compiles the scrive.
- `:BartlebyOpen` reopens the last scrive. `:BartlebyList` lists all scrives.

------------------------------------------------------------------------------
Concepts                                                     *bartleby-concepts*

Scrive - one writing project. It is a folder under `g:bartleby_binder_root`
that holds `project.json`, a `binder/` folder with the documents, and a
`compile/` folder with compile targets and their output.

Binder item - a folder or a document. A document also has a metadata file,
`<name>.meta.json`.

Structural folders - Front Matter, Manuscript, Back Matter, Characters, and
Research. Every scrive has them, and compile uses them. You cannot rename,
delete, or move them. `dd` on one clears its contents after a confirmation.
Chapter and Part folders inside Manuscript are also structural, but you can
add, move, and delete them.

------------------------------------------------------------------------------
Binder                                                         *bartleby-binder*

The Binder is the sidebar with the scrive's tree. It opens with the scrive,
and `:BartlebyToggleBinder` toggles it. Line 1 shows the scrive title. Folders
end with `/`. A document with a label shows the label color after its title.
Long titles wrap.

    Key                                Action ~

    `<CR>`                             Open the document, or expand or
                                       collapse the folder

    `<Tab>`                            Expand or collapse the folder

    `a`                                Add a document

    `A`                                Add a folder: Chapter or Part
                                       where the scrive type allows

    `dd`                               Delete the item after a
                                       confirmation. On a structural
                                       folder, clear its contents

    `r`                                Rename the item

    `J` / `K`                          Move a Chapter or Part down or up

    `>>` / `<<`                        Indent or outdent the item

    `l`                                Set the document's label

    `s`                                Set the document's status

    `L`                                Show or hide the `Chapter:` and
                                       `Part:` prefixes

    `S`                                Take a snapshot of the document

    `gS`                               View or restore snapshots

    `gc`                               Open the Corkboard for the folder

    `go`                               Open the Outliner for the folder

    `/`                                Search the scrive

    `?`                                Show this key list

    `q`                                Close the Binder

and synopsis.

    Key                         Action ~
    Arrows or `h` `j` `k` `l`   Move between cards
    `<CR>` or `<Space>`         Open the selected document
    `e`                         Edit the synopsis
    `J` / `K`                   Move the card later or earlier
    `?`                         Show this key list
    `<Esc>`                     Close the Corkboard

Outliner                                                     *bartleby-outliner*

`go` on a folder shows all items under it as a table: Title, Label, Status,
Words, Target, and Keywords. Rows are indented like the tree.

    Key         Action ~
    `j` / `k`   Move the selection
    `<CR>`      Open the document
    `l`         Set the document's label
    `s`         Set the document's status
    `gs`        Sort by a column. This changes the view only, not the tree
    `?`         Show this key list
    `q`         Close the Outliner

Inspector                                                   *bartleby-inspector*

`<leader>bi` or `:BartlebyToggleInspector` opens a read-only pane with the
current document's Title, Label, Status, Target, Keywords, and Synopsis. It
follows the document in the editor window.

    Key                         Action ~
    `e` on Label or Status      Pick a value
    `e` on Target or Keywords   Type a value
    `e` on Synopsis             Edit the synopsis. `<CR>` adds a line. `<C-s>` saves

Spotlight modes                                       *bartleby-spotlight-modes*

`<leader>bL` opens a searchable list of the modes, and
`:BartlebySpotlight {mode}` selects one by name. In the list, type to search,
or scroll with the arrow keys, `<PageUp>`, `<PageDown>`, or the mouse wheel.
Each part-of-speech mode keeps its words bright and dims everything else.
Markdown headings and Fountain scene headings, character cues, and transitions
dim completely.

    Mode                  Keeps bright          Source ~

    Paragraph             The paragraph with    
                          the cursor            

    Dialogue              Quoted speech. In     
                          Fountain, the         
                          dialogue under each   
                          character cue         

    Nouns                 Nouns and proper      Tagger only
                          nouns                 

    Verbs                 Main verbs            Tagger only

    Adjectives            Adjectives            Tagger only

    Adverbs               Adverbs               Tagger, else word
                                                list and the `-ly`
                                                ending

    Pronouns              Pronouns              Tagger, else word
                                                list

    Determiners           Articles and other    Tagger, else word
                          determiners such as   list
                          `this` and `every`    

    Prepositions          Prepositions          Tagger, else word
                                                list

    Conjunctions          Conjunctions          Tagger, else word
                                                list

    Auxiliaries           Helping verbs such as Tagger, else word
                          `was`, `have`, and    list
                          `can`                 

    Contractions          Contractions such as  Word list and pattern
                          `don't` and `they're` 

    Fillers               Filler words such as  Word list
                          `just`, `really`, and 
                          `very`                

    Passive               Passive constructions Tagger only
                          such as `was opened`  

Tagger. A tagger reads whole sentences, so it knows that "run" is a verb in
"they run" and a noun in "a long run". Word lists cannot know this, so Nouns,
Verbs, Adjectives, and Passive need a tagger and are hidden without one. To
use spaCy:

>sh
    python3 -m pip install spacy
    python3 -m spacy download en_core_web_sm
<
>vim
    let g:bartleby_spotlight_tagger = 'spacy'
<
The tagger starts when a mode first needs it and stays running. It receives
one paragraph at a time and does not receive text while you type. A paragraph
is tagged again when you leave Insert mode. If the tagger fails, Bartleby
reports the error once and hides the tagger modes.

Contractions. `'s` counts as a contraction only after the words in the
`s_contraction_words` list, such as `it`, `that`, and `there`. After other
words, `'s` is usually possessive, as in "John's hat", so it does not count.

Word lists. The lists are in `tools/pos/en.json`. They hold single words. To
add or remove words for a mode, use its name as a key:

>vim
    let g:bartleby_spotlight_words_add = {'Fillers': ['anyway', 'somehow']}
    let g:bartleby_spotlight_words_remove = {'Adverbs': ['well']}
<
With a tagger, all modes except Contractions and Fillers use the tagger, so
list changes affect only those two.

Fountain                                                     *bartleby-fountain*

Screenplay scrives use `.fountain` files. They have their own filetype and
syntax highlighting. Spotlight's Dialogue mode finds character cues and scene
headings in them.

Palette and menu                                     *bartleby-palette-and-menu*

`:BartlebyCommands` or `<leader>b<Space>` opens a searchable list of all
Bartleby commands. `:BartlebyMenu` or `<leader>bm` shows the same commands in
groups: Scrive, Binder, View, Document, and Project.

------------------------------------------------------------------------------
Session, snapshots, and search           *bartleby-session-snapshots-and-search*

Session - Bartleby remembers, for each scrive, the open document, the cursor
position, and which Binder folders are collapsed. It also remembers the last
scrive. To reopen it when Vim starts, set `g:bartleby_session_auto_restore`.

Snapshots - `S` in the Binder or `:BartlebySnapshot` saves a timestamped copy
of a document. `gS` or `:BartlebySnapshots` lists the copies and restores one.
A restore first takes a snapshot of the current text.

Search - `/` in the Binder or `:BartlebySearch` searches the scrive and puts
the results in the quickfix list.

------------------------------------------------------------------------------
Auto-save                                                   *bartleby-auto-save*

Bartleby saves changed scrive documents while you work, in the editor window
and in Focus mode. Other files are not affected.

- When you pause in Normal mode or leave Insert mode, it saves at most once
  every `g:bartleby_autosave_interval` seconds. A save that the interval skips
  runs when the interval ends.
- When you leave the document or Vim loses focus, it saves at once.

It writes only changed documents. To turn it off, set `g:bartleby_autosave` to
`0`.

Dictionary and thesaurus                     *bartleby-dictionary-and-thesaurus*

These need Merriam-Webster API keys. See Configuration #configuration.

`<leader>bd` shows the definition of the word under the cursor. `<leader>bt`
shows its synonyms. In Visual mode, both look up the selected text on one
line. `:BartlebyDefine {word}` and `:BartlebyThesaurus {word}` look up a typed
word.

    Key                                Action ~

    `j` / `k`                          Move the selection

    `<CR>` in the thesaurus            Replace the word in the text, with
                                       the same capitalization. For a
                                       typed word, copy the synonym to
                                       the unnamed register

    `<CR>` on a suggestion             Look up the suggestion

    `a`                                Show antonyms or synonyms

    `d`                                Show the definition of the
                                       selected word

    `?`                                Show this key list

    `q`                                Close

One `u` undoes a replacement. A misspelled word shows Merriam-Webster's
suggestions.

Results are cached in `~/.bartleby/lexicon_cache.json`, so a repeated lookup
sends no request. The cache does not contain your keys.

Each lookup needs its own key. Without the key, its mapping and its palette
and menu entries are not created, and its command reports the missing setting.
Set the keys before Bartleby loads, or use the `$BARTLEBY_MW_DICTIONARY_KEY`
and `$BARTLEBY_MW_THESAURUS_KEY` environment variables to keep them out of a
shared vimrc.

Compile                                                       *bartleby-compile*

`:BartlebyCompile` asks for the documents to include, a kind, a format, and
settings for that kind such as font, line spacing, and cover image. It saves
the answers as a named target that you can run again.

The selection pane lists the contents of Front Matter, Manuscript, and Back
Matter. Only these folders go into a compile.

    Kind                  Formats               Result ~

    Manuscript            PDF                   Submission format
                                                through sffms:
                                                double-spaced
                                                Courier, running
                                                header, and a title
                                                page with the word
                                                count

    Book                  PDF, HTML, EPUB,      A typeset book with
                          Markdown              chapter openings,
                                                running headers, a
                                                table of contents,
                                                and an optional cover
                                                image

    Screenplay            PDF, HTML, FDX        Standard screenplay
                                                format through
                                                screenplain

The tree sets the structure. A Chapter folder becomes a numbered chapter, and
each Front Matter and Back Matter document becomes an unnumbered chapter.
Other folders add no heading. In a Book PDF, front matter pages use roman
numerals, and page 1 is the first page of the main text.

Each Pandoc run writes a log to `~/.bartleby/logs/`, named for the scrive, the
target, and the time. Bartleby keeps the newest
`g:bartleby_compile_log_retention` logs for each target.

    Key in the selection pane   Action ~
    `x`                         Include or exclude the document. On a folder, all documents under it
    `<CR>`                      Accept the selection and continue
    `?`                         Show this key list
    `q`                         Cancel
