# AI Disclosure

This document states how AI assistants took part in this project and what people did.

## AI Tools

Claude and Claude Code.

## AI Work

- Planning and design, with human approval
- Code and its maintenance, with human code review
- Review of code that people wrote
- Debugging, with human help
- Documentation, with human proofreading
- GitHub workflows, with human design and review
- Automated regression tests

## Human Work

- Planning, design, and architecture
- Review of code that AI wrote
- Documentation, with AI proofreading
- Review of documentation and code comments that AI wrote
- Issues
- All Git activity
- Regression tests of the application and its user interface

## Skills

The AI assistants follow skills: written instructions that set the project's standards. A person wrote each skill. AI assistants then reviewed and revised it, and Claude Code measured and tested it.
